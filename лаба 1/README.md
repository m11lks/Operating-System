# Лабораторная работа №1. Управление файловой системой и асинхронный ввод-вывод

Работа посвящена двум темам:

1. **Управление файловой системой средствами Win32 API**: диски, тома, каталоги, файлы и их атрибуты.
2. **Асинхронный (перекрывающийся) ввод-вывод**: копирование файла асинхронными операциями и замер, как скорость копирования зависит от размера блока и числа одновременных операций.

## Состав

| Файл | Платформа | Что делает |
|---|---|---|
| [`labwin1.cpp`](labwin1.cpp) | Windows (Win32 API) | Консольное меню для работы с дисками, каталогами, файлами и атрибутами |
| [`lablin2.cpp`](lablin2.cpp) | Linux (POSIX AIO) | Асинхронное копирование файла через `aio_read` / `aio_write` с замером скорости |

---

## Windows: `labwin1.cpp`

Программа собрана в Unicode (`#define UNICODE`), поэтому для вывода используется `wcout`, а строки передаются как `TCHAR`. Работа идёт через иерархическое меню.

### Главное меню

| Пункт | Раздел | Используемые функции |
|---|---|---|
| 1 | Список дисков | `GetLogicalDrives` (битовая маска дисков A–Z), `GetLogicalDriveStrings` (строки вида `C:\`) |
| 2 | Информация о диске | `GetDriveType`, `GetVolumeInformation`, `GetDiskFreeSpace` |
| 3 | Работа с каталогами | `CreateDirectory`, `RemoveDirectory` |
| 4 | Создание файла | `CreateFile` с флагом `CREATE_NEW` |
| 5 | Копирование и перемещение | `CopyFile`, `MoveFile`, `MoveFileEx` (`MOVEFILE_COPY_ALLOWED \| MOVEFILE_REPLACE_EXISTING`) |
| 6 | Атрибуты и время файла | `GetFileAttributes`, `SetFileAttributes`, `GetFileInformationByHandle`, `GetFileTime`, `SetFileTime` |
| 0 | Выход | — |

### Подробнее

- **Тип диска** (`GetDriveType`): определяет, что за устройство стоит за буквой: `REMOVABLE`, `FIXED`, `REMOTE`, `CDROM`, `RAMDISK` или `NO_ROOT_DIR`.
- **Информация о томе** (`GetVolumeInformation`): метка тома, серийный номер, файловая система (NTFS, FAT32 и т.п.) и расшифровка флагов ФС: поддержка сжатия, шифрования, Unicode-имён, ACL, регистрозависимого поиска, режим «только чтение».
- **Свободное место** (`GetDiskFreeSpace`): число секторов в кластере и байт в секторе. Из них вычисляются размер кластера и общий, свободный и занятый объём в МБ и ГБ.
- **Атрибуты файла**: выводятся все установленные флаги (`ARCHIVE`, `HIDDEN`, `READONLY`, `SYSTEM`, `COMPRESSED`, `ENCRYPTED`, `SPARSE_FILE` и др.). При изменении выбранный атрибут переключается через XOR, поэтому повторный выбор снимает его. Пункт «Normal» сбрасывает все атрибуты.
- **Информация по дескриптору** (`GetFileInformationByHandle`): серийный номер тома, индекс файла, число жёстких ссылок, размер.
- **Время файла**: `GetFileTime` возвращает время создания, последнего доступа и изменения. Оно переводится из `FILETIME` в локальное время через `FileTimeToSystemTime` и `SystemTimeToTzSpecificLocalTime`. `SetFileTime` выставляет все три отметки в текущее системное время.

Ошибки обрабатываются единообразно: при неудаче выводится код из `GetLastError()`.

### Сборка и запуск

MinGW:

```bash
g++ labwin1.cpp -o labwin1.exe
```

MSVC (Developer Command Prompt):

```bash
cl /EHsc labwin1.cpp
```

## Linux: `lablin2.cpp`

Копирование файла средствами **POSIX AIO** (`<aio.h>`). Аналог перекрывающегося ввода-вывода Windows (`ReadFileEx` / `WriteFileEx`).

### Как это работает

- Для каждой асинхронной операции заводится структура `aio_operation`: в ней лежат `aiocb`, буфер, дескрипторы источника и приёмника и указатели на общие атомарные счётчики.
- Уведомление о завершении приходит через `SIGEV_THREAD`: по окончании операции система вызывает `aio_completion_handler` в отдельном потоке.
- Обработчик реализует цепочку **чтение → запись → следующее чтение**:
  1. закончилось чтение, тогда запускается `aio_write` прочитанного блока по тому же смещению;
  2. закончилась запись, тогда атомарно (`std::atomic::fetch_add`) берётся следующее свободное смещение и запускается `aio_read`;
  3. файл закончился, тогда счётчик активных операций уменьшается.
- Главный поток ждёт, пока счётчик активных операций не станет равен нулю. Время замеряется через `clock_gettime(CLOCK_MONOTONIC)`.
- В конце выводятся время копирования и скорость в МБ/с.

### Режимы меню

| Пункт | Тест | Что меняется |
|---|---|---|
| 1 | Block size test | Размер блока задаётся вручную, одна операция |
| 2 | Num operations test | Блок фиксирован (`4096` байт), число параллельных операций: 1, 2, 4, 8, 12 или 16 |

Так можно получить два графика: скорость от размера блока и скорость от числа одновременных операций.

### Сборка и запуск

```bash
g++ lablin2.cpp -o lablin2 -lrt
```

```bash
./lablin2
```

Для наглядного замера стоит взять файл побольше (сотни МБ), например:

```bash
dd if=/dev/urandom of=big.bin bs=1M count=512
```
